# 📈 StockSage

### Interactive Stock Market Analysis & Portfolio Dashboard

StockSage is an interactive web application built with Python and Streamlit that allows users to analyze stocks, view historical performance, explore technical indicators, and track their portfolio.

## ✨ Features

- 📊 Interactive stock analysis
- 💰 Current stock price and market data
- 📈 Moving averages
- 📉 52-week high and low
- 📅 Historical stock performance
- 💼 Portfolio tracking
- 🔍 Support for multiple stocks
- 🎨 Clean and user-friendly dashboard

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **yFinance**
- **Pandas**
- **SQLite**
- **Git & GitHub**

## 🖥️ Dashboard

StockSage provides an easy-to-use interface for analyzing stocks and monitoring portfolio performance.
